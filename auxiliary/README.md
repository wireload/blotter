## How to translate

1. Edit every `.xib` to make sure alignment and placement is perfect. Try to give as much width as possible to every label so that wider languages will fit well.
2. Edit `Meta.strings` with new "What's New" and any updates to the main text.
3. Edit `localization.py`.
    1. For each new `.m` file with a localisable string, add it under `Sources()`.
    2. For each new `.xib` file, add it under `Xibs()`.
    3. Remove any `.m` or `.xib` files which no longer exist in the source tree.

4. Run `localization.py` in "generate strings" mode:

        python auxiliary/localization.py strings

5. Edit `litany.yml`.
    1. Add new `strings` sections to correspond to each new `.strings` generated by `localization.py` in the previous step.
    2. Remove any `strings` sections no longer generated.
    3. In the `skip` section, add any keys which are not necessary to translate and which should be ignored.

6. Create the new global `.strings` file:

        python auxiliary/litany.py create_global new.strings sv && iconv -f utf-16 -t utf-8 new.strings >new-utf8.strings

7. Grab a copy of the old strings:

        git checkout <last release version tag>
        python auxiliary/litany.py create_global old.strings sv && iconv -f utf-16 -t utf-8 old.strings >old-utf8.strings
        git checkout master

8. Compare the new strings to the old strings:

        diff -w old-utf8.strings new-utf8.strings

9. Update mygengo using the diff.
10. Enter standard system translations when known. Search for standard translations using commands such as:

        # First mount OS X glossary "russian.dmg" from https://developer.apple.com/downloads/index.action.
        python auxiliary/greptrans.py ru "keyboard shortcuts"

    This example is for Russian. Just substitute `sv`, `es`, etc. for other languages. Current language codes we use are `de`, `es`, `fr`, `ko`, `ru`, `sv`, `ja`.

11. Order translations.
12. Export all languages from MyGengo with the "Download files > All languages" option.
13. Run `litany.py` in reverse:

        unzip ~/Downloads/lang_files.zip -d ./lang_files
        sh auxiliary/litany_reverse_all.sh

14. Commit the new `.strings`.
15. Create the language specific xibs using `localization.py`:

        python auxiliary/localization.py xibs

16. Edit each language specifix xib to make sure labels and buttons are large enough to fit their translated text.
17. Compile the app and run it usign Language Switcher. Test every screen in every language.
