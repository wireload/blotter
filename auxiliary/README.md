## How to translate

1. Edit every `.xib` to make sure alignment and placement is perfect. Try to give as much width as possible to every label so that wider languages will fit well. 
2. Edit `localization.py`.
    1. For each new `.m` file with a localisable string, add it under `Sources()`.
    2. For each new `.xib` file, add it under `Xibs()`.
    3. Remove any `.m` or `.xib` files which no longer exist in the source tree.

3. Run `localization.py` in "generate strings" mode:

        python auxiliary/localization.py strings

4. Edit `litany.yml`.
    1. Add new `strings` sections to correspond to each new `.strings` generated by `localization.py` in the previous step.
    2. Remove any `strings` sections no longer generated.
    3. In the `skip` section, add any keys which are not necessary to translate and which should be ignored.

5. Create the new global `.strings` file:

        python auxiliary/litany.py create_global new.strings sv
        iconv -f utf-16 -t utf-8 new.strings >new-utf8.strings

6. Grab a copy of the old strings:

        git checkout <last release version tag>
        python auxiliary/litany.py create_global old.strings sv
        iconv -f utf-16 -t utf-8 old.strings >old-utf8.strings
        git checkout master

7. Compare the new strings to the old strings:

        diff -w old-utf8.strings new-utf8.strings

8. Update mygengo using the diff.
9. Order translations.
10. Export each language as a `.strings` file from mygengo.
11. Run `litany.py` in reverse:

        python auxiliary/litany.py process_global mygengo_<language>.strings <language>

12. Commit the new `.strings`.
13. Create the language specific xibs using `localization.py`:

        python auxiliary/localization.py xibs

14. Edit each language specifix xib to make sure labels and buttons are large enough to fit their translated text.
15. Compile the app and run it usign Language Switcher. Test every screen in every language.
